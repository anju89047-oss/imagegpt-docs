# GPT Image 1.5

An image-to-image model (`GPT-IMAGE-1.5`) available through the ImageGPT [Image Generation API](./index.mdx). The example below uses image-to-image (`/generate/image-image`) with an input image.

| Property | Value |
| --- | --- |
| Model ID | `GPT-IMAGE-1.5` |
| Playground | [Image](./index.mdx) |
| Pricing | 25 credits per image |

## Headers

Send your API key in the `x-api-key` header on every request. See
[Authentication](../authentication.mdx) for details.

| Header | Required | Value |
| --- | --- | --- |
| `x-api-key` | Yes | `YOUR_API_KEY` |
| `Content-Type` | Yes | `application/json` |

A missing or invalid key returns **401 Unauthorized**.

## Parameters

Request body fields for `/generate/image-image`:

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `model` | `string` | Yes | — | Model ID to use for generation. See the model list below for all available IDs. |
| `prompt` | `string` | Yes | — | Text description of the image you want to generate. |
| `width` | `number` | No | `512` | Output image width in pixels. |
| `height` | `number` | No | `512` | Output image height in pixels. |
| `outputType` | `string` | No | `"binary"` | Output delivery format. One of "binary" (image blob), "url" (hosted link), or "base64" (encoded string). |
| `outputFormat` | `string` | No | `"png"` | Image file format. Either "png" or "jpg". |
| `image` | `string[]` | No | — | Array of input image URLs (max 3). Required only for image-to-image generation. |

fetch('https://api.imagegpt.online/generate/image-image', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
  },

  "prompt": "Photorealistic portrait of the same person (keep his real face unchanged). Soft diffused lighting, smooth steel-blue background, slightly elevated front angle warm, intimate, digital photo",
  "width": 512,
  "height": 512,
  "model": "GPT-IMAGE-1.5",
  "outputType": "binary",
  "outputFormat": "png",
  "image": [
    "https://ai.imagegpt.online/sample/437104513_792860259041679_1643623203130153012_n.jpg"
  ]

})
  .then(res => res.blob())
  .then(blob => {

    document.body.appendChild(img);
  });

## Response example

**binary**

```js
const blob = await response.blob();
const url = URL.createObjectURL(blob);
```

**url**

```json
{
  "success": true,
  "taskId": "imagegpt_img-...",
  "url": "https://...",
  "creditsDeducted": 3
}
```

**base64**

```json
{
  "success": true,
  "taskId": "imagegpt_img-...",
  "base64": "/9j/4QWm...",
  "creditsDeducted": 3
}
```

## Pricing

**25** credits per image. Each image deducts the credit value shown for the selected model.
