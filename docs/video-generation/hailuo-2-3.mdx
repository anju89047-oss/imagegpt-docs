# Hailuo 2.3

A video model (`HAILUO-2.3`) available through the ImageGPT [Video Generation API](./index.mdx). The example below uses image-to-video (`/generate/image-video`) and returns a `taskId`.

| Property | Value |
| --- | --- |
| Model ID | `HAILUO-2.3` |
| Playground | [Video](./index.mdx) |
| Durations (s) | 6, 10 |
| Resolutions | 720p, 1080p |
| Pricing | 720p: 30 · 1080p: 40 (credits/s) |

## Headers

Send your API key in the `x-api-key` header on every request. See
[Authentication](../authentication.mdx) for details.

| Header | Required | Value |
| --- | --- | --- |
| `x-api-key` | Yes | `YOUR_API_KEY` |
| `Content-Type` | Yes | `application/json` |

A missing or invalid key returns **401 Unauthorized**.

## Parameters

Request body fields for `/generate/image-video`:

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `model` | `string` | Yes | — | Model ID to use for generation, e.g. KLING-3.0-TURBO, SEEDANCE-2.0-MINI, WAN-2.7-VIDEO, HAILUO-2.3, GROK-IMAGINE-VIDEO-1.5, GEMINI-OMNI, HAPPYHORSE-1.1. |
| `prompt` | `string` | Yes | — | Text description of the video (or, for image-video, how the image should be animated). |
| `duration` | `number` | Yes | — | Length of the video in seconds. Valid values depend on the selected model (e.g. 4–15s, or fixed 6/10s for some models). |
| `resolution` | `string` | Yes | — | Output resolution. One of "480p", "720p", or "1080p" depending on model support — pricing varies per resolution. |
| `aspect_ratio` | `string` | No | `"16:9"` | Output aspect ratio. One of "16:9", "9:16", or "1:1". |
| `image` | `string[]` | No | — | Array containing the source image URL. Required only for image-to-video generation (/generate/image-video). |

:::tip Asynchronous model
Submitting a task returns a `taskId`. Poll the result with the
[Check Video Status](./video-status.mdx) API.
:::

## Response example

**create**

```json
{
  "success": true,
  "taskId": "imagegpt-vid-...",
  "status": "waiting",
  "creditsDeducted": 125
}
```

**status · url**

Returns JSON. status is "waiting" while rendering, then "success" with a hosted video url once done.

```json
{
  "success": true,
  "status": "success",
  "url": "https://...mp4"
}
```

**status · binary**

Returns the raw video file directly once it's ready (no JSON wrapper).

```js
const blob = await response.blob();
const url = URL.createObjectURL(blob);
```

## Pricing

Charged in **credits per second of footage**. The per-second rate depends on both the model and the chosen resolution. Total cost = credits/second × duration.

| Resolution | Credits / second |
| --- | --- |
| 720p | 30 |
| 1080p | 40 |

For example, a 6s clip at 720p costs 180 credits.
