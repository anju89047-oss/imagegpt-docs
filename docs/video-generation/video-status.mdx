# Check Video Status

Video generation is asynchronous. A submit call to
[`/generate/text-video`](./index.mdx) or [`/generate/image-video`](./index.mdx)
returns a `taskId` immediately. Poll this endpoint until `status` is
`success`, then read the video `url`.

`GET /generate/video-status`

Poll task status. Query params: taskId, outputType (url|binary).

## Headers

| Header | Required | Value |
| --- | --- | --- |
| `x-api-key` | Yes | `YOUR_API_KEY` |

## Query parameters

| Parameter | Required | Default | Description |
| --- | --- | --- | --- |
| `taskId` | Yes | — | The task ID from the create response. |
| `outputType` | No | `url` | "url" returns JSON with a hosted video URL; "binary" returns the raw video file. |

## Response example

**outputType: url**

Returns JSON. status is "waiting" while rendering, then "success" with a hosted video url once done.

```json
{
  "success": true,
  "status": "success",
  "url": "https://...mp4"
}
```

**outputType: binary**

Returns the raw video file directly once it's ready (no JSON wrapper).

```js
const blob = await response.blob();
const url = URL.createObjectURL(blob);
```
