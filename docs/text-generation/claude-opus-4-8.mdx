# CLAUDE OPUS 4.8

A text model (`CLAUDE-OPUS-4.8`) available through the ImageGPT [Text Generation API](./index.mdx).

| Property | Value |
| --- | --- |
| Model ID | `CLAUDE-OPUS-4.8` |
| Playground | [Text](./index.mdx) |
| Pricing | 50 credits per 1,000 output tokens |

## Headers

Send your API key in the `x-api-key` header on every request. See
[Authentication](../authentication.mdx) for details.

| Header | Required | Value |
| --- | --- | --- |
| `x-api-key` | Yes | `YOUR_API_KEY` |
| `Content-Type` | Yes | `application/json` |

A missing or invalid key returns **401 Unauthorized**.

## Parameters

Request body fields for `/generate/text`:

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `model` | `string` | Yes | — | Model ID to use for generation. See the model list below for all available IDs. |
| `prompt` | `string` | Yes | — | The user prompt / instruction to send to the model. |
| `system` | `string` | No | `""` | Optional system message to set the model's behavior or persona. |
| `outputType` | `string` | No | `"text"` | Output format. Use "text" for plain text or "json" to receive a structured JSON response. |
| `maxTokens` | `number` | No | `model max` | Maximum number of output tokens to generate. Minimum value is 100. |

## Request examples

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl -X POST https://api.imagegpt.online/generate/text \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{"model":"CLAUDE-OPUS-4.8","prompt":"Build a simple Tic Tac Toe game using only HTML, CSS, and JavaScript with two-player turn-by-turn gameplay and a restart button after the game ends.","system":"You are a friendly assistant.","outputType":"text"}'
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js
fetch('https://api.imagegpt.online/generate/text', {
  method: 'POST',

    'Content-Type': 'application/json',
```
