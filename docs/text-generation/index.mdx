# Text Generation API

A unified REST API to generate text using 20+ AI models from OpenAI, Google, Anthropic, DeepSeek, Perplexity, and more — all through a single endpoint with a credit-based pricing system.

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| `POST` | `/generate/text` | Generate text / chat completions from a prompt. |

## Parameters

Request body fields for `/generate/text`:

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `model` | `string` | Yes | — | Model ID to use for generation. See the model list below for all available IDs. |
| `prompt` | `string` | Yes | — | The user prompt / instruction to send to the model. |
| `system` | `string` | No | `""` | Optional system message to set the model's behavior or persona. |
| `outputType` | `string` | No | `"text"` | Output format. Use "text" for plain text or "json" to receive a structured JSON response. |
| `maxTokens` | `number` | No | `model max` | Maximum number of output tokens to generate. Minimum value is 100. |

:::note
When using outputType: "json", instruct the model in your prompt to respond in valid JSON format for best results.
:::

## Response example

**text**

```text
A plain text string from the model.
```

**json**

```json
{
  "success": true,
  "output": "...",
  "usage": {
    "inputTokens": 0,
    "outputTokens": 0,
    "creditsDeducted": 0
  }
}
```

## Examples

```js title="Text completion (fetch)"
fetch('https://api.imagegpt.online/generate/text', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
  },
  body: JSON.stringify({
    model: 'GEMINI-2.5-FLASH-LITE',
    system: 'You are a helpful assistant.',
    prompt: 'Explain quantum computing in one paragraph.',
    outputType: 'text',
    maxTokens: 300
  })
})
  .then(res => res.text())
  .then(console.log);
```

## Pricing

Charged in **credits per 1,000 output tokens**. Input tokens are always free. The credit value shown per model is charged per 1,000 output tokens.
