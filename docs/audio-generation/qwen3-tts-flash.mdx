# Qwen3 TTS Flash

A text-to-speech model (`QWEN3/TTS-FLASH`) available through the ImageGPT [Audio (Text to Speech) API](./index.mdx).

| Property | Value |
| --- | --- |
| Model ID | `QWEN3/TTS-FLASH` |
| Playground | [Audio](./index.mdx) |
| Pricing | 10 credits per request |

## Headers

Send your API key in the `x-api-key` header on every request. See
[Authentication](../authentication.mdx) for details.

| Header | Required | Value |
| --- | --- | --- |
| `x-api-key` | Yes | `YOUR_API_KEY` |
| `Content-Type` | Yes | `application/json` |

A missing or invalid key returns **401 Unauthorized**.

## Parameters

Request body fields for `/generate/text-speech`:

| Parameter | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `prompt` | `string` | Yes | — | The text you want to convert to speech. |
| `model` | `string` | Yes | — | Model ID to use. E.g. QWEN3/TTS-FLASH, ELEVENLABS/TTS, OPENAI/GPT-AUDIO-MINI. |
| `outputType` | `string` | No | `"binary"` | Use "binary" to receive raw audio bytes, or "url" to get a hosted audio URL in JSON. |
| `voice` | `string` | No | `"alloy"` | Voice name (applies to OpenAI and ElevenLabs models only). E.g. alloy, nova, rachel, josh. |
| `outputFormat` | `string` | No | `"mp3"` | Audio format for the output (applies to OpenAI and ElevenLabs models only). Currently mp3. |

## Request examples

<Tabs groupId="lang">
<TabItem value="curl" label="cURL">

```bash
curl -X POST https://api.imagegpt.online/generate/text-speech \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{"prompt":"ImageGPT is an AI platform to generate images, videos, audio, code, and chat responses using multiple advanced models in one place.","model":"QWEN3/TTS-FLASH","outputType":"binary","voice":"alloy","outputFormat":"mp3"}'
```

</TabItem>
<TabItem value="js" label="JavaScript">

```js
fetch('https://api.imagegpt.online/generate/text-speech', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'YOUR_API_KEY'
  },
  body: JSON.stringify({
  "prompt": "ImageGPT is an AI platform to generate images, videos, audio, code, and chat responses using multiple advanced models in one place.",
  "model": "QWEN3/TTS-FLASH",
  "outputType": "binary",
  "voice": "alloy",
  "outputFormat": "mp3"
})
})
  .then(res => res.blob())
  .then(blob => {
    const audio = new Audio(URL.createObjectURL(blob));
    audio.play();
  });
```

</TabItem>
<TabItem value="python" label="Python">

```python
import requests

resp = requests.post(
    "https://api.imagegpt.online/generate/text-speech",

        "model": "QWEN3/TTS-FLASH",
        "outputType": "binary",
        "voice": "alloy",
        "outputFormat": "mp3"
    },
)
with open("speech.mp3", "wb") as f:
    f.write(resp.content)
```
